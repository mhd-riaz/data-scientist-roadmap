# 🎓 My Data Science & AI Notebook — M.Tech Journey

This repo is my personal **bible** for the M.Tech in Data Science & AI — every subject,
every semester, distilled into reference notes I can search, revisit, and build on.

It's organized so the learning curve reads **bottom to top**: Semester 1 (foundations)
at the top of the index, each later semester building on the one before it.

## 📖 How this repo is organized

```
semester-<n>/                      → one folder per semester, in learning order
  README.md                        → index of that semester's subjects
  <nn>-<subject-name>/             → one folder per subject, numbered in study order
    README.md                      → subject overview, topic checklist, links, resources
    notes/                         → markdown reference notes (theory, concepts, cheat sheets)
    notebooks/                     → Jupyter notebooks for hands-on / coding subjects
    queries/                       → .sql files (DB/SQL subjects only)
```

Every subject README follows the same template: **Overview → Topics Covered → Notes →
Notebooks → Resources → Key Takeaways**, so any subject is navigable the same way.

## ✍️ Conventions

- Each subject folder is numbered in the order it should be studied within its semester.
- `notes/` files are numbered markdown notes (`01-introduction.md`, `02-...md`, ...) —
  one file per topic/lecture, using the shared note template.
- `notebooks/` hold hands-on practice/code — one notebook per topic, prefixed `00-`, `01-`, ...
- Keep entries short and factual; this is a reference, not a diary.
